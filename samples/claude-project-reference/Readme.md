# Claude Project Reference

Reference files for a Claude project (claude.ai) that authors degree files: project
instructions, a generation guide, a quick reference, an example degree and a copy of the
degree schema.

`schema-v5.2.yaml` is a snapshot and has drifted from the authoritative schema,
`src/assets/Degree-schema.yaml`. Refresh it from there before uploading it to a project.
For Claude Code, `nuanalytics init` sets up skills and the MCP server instead, and the
server serves the current schema.
